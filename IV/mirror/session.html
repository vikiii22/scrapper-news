Importar sesión real en el mirror local

Esta página escribe los datos solo en el localStorage, sessionStorage y cookies de 127.0.0.1. No los envía al servidor ni los guarda en disco.

Importante: usa únicamente tu propia cuenta. Los tokens son credenciales: no los pegues en chats, issues, capturas ni en el repositorio.

1. Exportar desde Tulotero

Con la sesión iniciada en https://web.tulotero.es, abre DevTools → Console y ejecuta:

copy(JSON.stringify({ localStorage: { ...localStorage }, sessionStorage: { ...sessionStorage } }))

Eso copia al portapapeles todos los datos de sesión, incluidos el access token, el refresh token y el identificador de instalación, tanto si elegiste «No cerrar sesión» (localStorage) como si no (sessionStorage). Si necesitas también las cookies no HttpOnly, usa: 

copy(JSON.stringify({ localStorage: { ...localStorage }, sessionStorage: { ...sessionStorage }, cookies: Object.fromEntries(document.cookie.split('; ').filter(Boolean).map(c => { const i = c.indexOf('='); return [c.slice(0, i), c.slice(i + 1)]; })) }))

2. Importar en local

Pega el JSON y pulsa importar. Después se recargará la portada local.

Qué se importa

  • localStorage / sessionStorage: se copian todas las claves de ambos. La app usa 0x01 (access token), 0x44 (estrategia), 0x45 (refresh token), 0x46 (URL de refresh) y 0x47 (caducidad), además de la instalación/dispositivo. Según hayas marcado «No cerrar sesión», los tokens pueden estar en uno u otro.
  • cookies: solo si las incluyes. Se escriben con path=/; las cookies HttpOnly no se pueden copiar desde JavaScript y, en general, no son necesarias para este front.
